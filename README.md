# Noya · 早期单文件版本

这是 Noya 项目**最早的一个可运行版本**——921 行单文件，命令行交互。
后来它才被拆成 34 个模块的工程结构。

## 它能做什么

- **对话**：接本地 Ollama（`qwen2.5:3b`），支持多轮历史
- **语音**：faster-whisper 识别 + pyttsx3 合成
- **系统监控**：电量、CPU、空闲状态，后台线程轮询
- **环境感知**：当前窗口 / 进程
- **工具调用**：时间、天气、打开应用、系统操作
- **长期记忆**：ChromaDB + 向量检索
- **日程提醒**：ics 日历解析

## 怎么跑

```bash
pip install chromadb faster-whisper ics numpy psutil pygetwindow pynput pyttsx3 requests speech_recognition win10toast
ollama pull qwen2.5:3b
python butler.py
```

## 已知限制（如实写）

- **单文件 921 行，没有测试**
- 调试输出没删（运行时能看到 `[DEBUG] LLM 原始响应`）
- 仅 Windows（系统通知、窗口检测依赖 Win32）
- 语音模型首次运行需下载约 460 MB

## 为什么公开

这是学习过程的真实产物，**包括它粗糙的部分**。

它之后经历了一次模块化重构，那次重构里出过一个事故：
**121 条自动化测试全绿，程序一启动却崩掉** —— 根因是新函数缩进错误插入类体，
其后 16 个方法被吞成嵌套函数，而 121 条测试中没有任何一条构造过主窗口对象。

那件事之后我才开始要求自己：**每条判据必须先能对旧版本失败，否则不算数。**
